# Lösungen

Musterlösungen für die Aufgaben-Notebooks in diesem Repository. Öffne eine Lösung neben dem zugehörigen Notebook, um deine Arbeit zu überprüfen.

| Datei / Ordner | Beschreibung |
|---|---|
| [**2 - XGBoost**](2_applying_xgboost.ipynb) | Musterlösung: die Diabetes-Daten laden und aufteilen, einen `XGBClassifier` trainieren, ihn mit einem Classification Report und einer Confusion Matrix evaluieren, dann die Entscheidungsfläche über einem Feature-Raster abbilden und in 3D darstellen. |
| [**3 - Vergleich von Klassifikatoren**](3_comparison_classification_algorithms_exercise.ipynb) | Musterlösung für die CharityML-Aufgabe mit den Zensusdaten: Vorverarbeitung (Log-Transformationen, One-Hot Encoding, Skalierung), eine naive Baseline, ein Vergleich von Entscheidungsbaum, SVM und AdaBoost, dann das Tuning des besten Modells mit `GridSearchCV` und ein Retraining mit verkleinertem Feature-Set. |
